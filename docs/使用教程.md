## 1. 这是什么

一个运行在浏览器里的抖音网页版自动化助手，装好后抖音页面右侧会出现一个可拖动的
「🎵 抖音自动获客助手」面板。它能按你设定的关键词或视频链接列表，自动逐个视频执行：

- **点赞**（模拟按下快捷键 Z）
- **收藏**（模拟按下快捷键 C）
- **评论**：自动打开评论区，回复别人的一级评论，或直接发布新评论；
  评论内容可以是表情、预设文案（随机一条）或 AI 生成的个性化回复，还可以附带你收藏的图片

适合场景：账号冷启动互动、评论区维护、意向客户触达等（请务必阅读[第 11 节](#11-使用建议与风险提示)）。

| --- | --- | --- |

### 第二步：安装本脚本

**方式 A（推荐）：脚本站安装**

打开脚本发布页，点「安装」即可，之后可自动接收更新。

**方式 B：GitHub 直装**

1. 打开 <https://github.com/onedarren/DYhuokezhushou/raw/main/dist/抖音自动获客助手-obfuscated.user.js>
2. 脚本管理器会自动弹出安装确认页，点「安装」

**方式 C：手动粘贴**

1. 下载仓库里的 `dist/抖音自动获客助手-obfuscated.user.js`，用记事本打开，全选复制
2. 点击脚本管理器图标 → 「添加新脚本」→ 清空模板 → 粘贴 → 保存（Ctrl+S）

没出现的话，先刷新页面，再检查脚本开关是否打开。

## 3. 首次使用：跑通第一个任务

建议先用小参数试跑一次，确认全流程没问题再放大：

1. 打开抖音并**登录**（未登录无法点赞/评论）
2. 打开右侧面板，保持默认的「关键词搜索模式」
3. 搜索关键词填一个具体词，例如：`美食探店`
4. 操作类型：只勾「点赞」+「评论」，评论方式选「直接评论」，评论类型选「仅表情回复」
5. 把「每视频评论数」「每关键词视频数」都改成 **1**，评论间隔改成 **10** 秒
6. 点「开始任务」——脚本会自动打开搜索页 → 进入第一个视频 → 点赞 → 评论 → 面板显示进度
7. 跑完 1 个视频后任务自动结束，确认评论确实发出去了，再按真实需求配置正式任务

## 4. 两种任务模式详解

### 关键词搜索模式（默认）

脚本按关键词打开抖音搜索页（自动带 `?type=video` 只搜视频），对搜索结果逐个视频执行操作。

| 设置项 | 怎么填 |
| --- | --- |
| 搜索关键词 | 多个关键词用**英文逗号**分隔，如 `注册公司,注销公司,代记账`。脚本会先把中文逗号「，」顿号「、」自动转成英文逗号 |
| 排序依据 | 综合排序 / 最新发布 / 最多点赞，留空则不筛选 |
| 发布时间 | 一天内 / 一周内 / 半年内。做时效性内容互动建议选「一周内」 |
| 视频时长 | 1分钟以下 / 1-5分钟 / 5分钟以上 |
| 搜索范围 | 关注的人 / 最近看过 / 还未看过 |
| 每关键词视频数 | 每个关键词处理多少个视频后切换下一个关键词 |

执行顺序：关键词 1 的 N 个视频 → 关键词 2 的 N 个视频 → …… → 全部完成自动弹通知。

### 视频链接模式

适合已经有一份精准视频列表的情况。每行一条链接，支持两种格式：

```
https://www.douyin.com/video/742xxxxxxxxxxxxxxx
https://www.douyin.com/jingxuan?modal_id=742xxxxxxxxxxxxxxx
```

- `/video/` 链接会自动转换成弹窗播放形式
- 无效链接会被自动跳过（控制台有日志）
- 视频之间通过页面跳转切换，每条链接处理完后自动打开下一条

获取链接的方法：电脑版抖音打开目标视频，直接复制浏览器地址栏。

## 5. 操作类型：点赞 / 收藏 / 评论

三个复选框任意组合，至少选一个：

- **点赞**：进入视频后按 `Z` 键点赞。脚本会先检测当前状态，已点赞的视频自动跳过，不会取消点赞
- **收藏**：按 `C` 键收藏，同样带状态检测
- **评论**：完整评论流程（详见下节）

只要点了赞/藏的多了，账号活跃度会自然提升，新账号建议前期只开点赞，跑几天再加评论。

## 6. 评论功能详解

### 评论方式

| 方式 | 行为 |
| --- | --- |
| **直接评论**（direct） | 不看别人的评论，直接在视频下发布新评论。脚本会先检测你是否已在该视频评论过，评论过就跳过，避免刷屏 |
| **回复评论**（reply） | 打开评论区，逐条查看别人的一级评论，点「回复」按钮进行回复。适合精准触达：谁在评论区活跃就回复谁 |

### 评论类型

| 类型 | 行为 |
| --- | --- |
| **仅表情回复** | 点开表情面板随机发一个表情，最安全、最快 |
| **文本回复** | 从你填写的文案库中随机取一条发送，每行一条，例如：`讲得真好[赞]`、`学到了，感谢分享` |
| **AI回复** | 调用大模型，结合视频描述 + 对方评论内容生成个性化回复，拟真度最高（需配置 API Key，见下一节） |

### 评论流程的小细节（自动处理，无需操心）

- 文本/AI 模式下，脚本会先点一个表情占位再替换成文字（绕过输入框限制）
- **图片评论**：勾选后，评论时自动附加你抖音账号「收藏图片」中的第 N 张（填写序号）
- **回复过滤**：可设置「包含关键词」（只回复含这些词的评论）和「排除关键词」（跳过含广告、联系方式等的评论）
- **防重复**：脚本通过头像标识记录处理过的评论，同一视频不会重复回复；检测到自己已回复过子评论会整条跳过
- **仅一级评论**：默认勾选，只回复一楼评论，不深入子评论串

## 7. AI 评论配置

评论类型选「AI回复」后展开配置：

| 平台 | 获取 API Key | 说明 |
| --- | --- | --- |
| DeepSeek | <https://platform.deepseek.com> | 便宜，中文质量好，**推荐首选** |
| Kimi（月之暗面） | <https://platform.moonshot.cn> | 中文自然 |
| OpenAI | <https://platform.openai.com> | 需要海外支付 |
| OpenRouter | <https://openrouter.ai> | 聚合平台，一个 Key 用多家模型 |
| 小米 MiMo | 小米开放平台 | 国产新选择 |
| Gemini | <https://aistudio.google.com> | 有免费额度 |
| Ollama | 本地运行，无需 Key | 接口地址填 `http://127.0.0.1:11434/v1/chat/completions`，可自定义模型名 |

**配置步骤（以 DeepSeek 为例）**：

1. 注册并登录平台 → 创建 API Key → 复制
2. 面板：AI 模型选 `DeepSeek` → API Key 粘贴 → 保存配置
3. **AI 提示词**决定评论的风格，默认是通用友好型，可以自定义，例如：
   ```
   你是一个做工商注册服务的抖音用户，请根据视频内容和用户评论给出自然的回复，
   口吻像真实网友，不要太营销号，15字以内，可以适当带一个表情。
   ```
4. 点「保存配置」→ 开一次任务测试，看发出的评论效果再调整提示词

> 🔒 **API Key 安全**：Key 只保存在你自己浏览器的脚本存储里，仅用于直连对应平台，
> 不经过任何第三方服务器（本脚本无自己的后端）。

## 8. 高级设置

| 设置 | 默认 | 建议 |
| --- | --- | --- |
| 每视频评论数 | 3 | 每个视频评论几条（回复模式下是回复几条评论） |
| 每关键词视频数 | 2 | 关键词模式下每个关键词处理几个视频 |
| 评论间隔(秒) | 3 | 两次评论的最小间隔，实际会再加 0~1 秒随机值。**新账号建议 60~120 秒** |
| 仅一级评论 | 开 | 只回复一楼，不进子评论串 |
| 回复前点赞 | 关 | 回复之前先给那条评论点个赞，更自然 |

**新账号保守参数参考**：每视频评论 1 条、间隔 90 秒、每天总评论量控制在 30 条以内、只回复不直接评论。

## 9. 进度面板与任务管理

任务开始后面板下方出现进度区：

- **状态**：运行中 / 已完成 / 错误信息
- **当前关键词**：正在处理的关键词
- **关键词进度 / 视频进度 / 评论进度**：`已完成/总数`
- **进度条**：整体完成百分比

**常用操作**：

- 「停止任务」：随时可停，已保存的配置不受影响
- **换页不断**：任务跨页面执行（搜索页→视频→下一个关键词），进度存在浏览器里，中途关掉标签页，重新打开抖音后面板会显示进度；卡住超过 5 分钟脚本会自动尝试恢复
- 面板**标题栏可拖动**，位置自动记住；点一下标题栏折叠成小球，再点小球展开
- 所有配置（关键词、API Key、文案库）保存后永久生效，下次打开不用重填

## 10. 常见问题 FAQ

**Q：安装后抖音页面没有出现面板？**
确认脚本已启用；刷新页面；确认地址是 `www.douyin.com`（其他域名不生效）。还没出现就按 F12 看控制台有没有 `[抖音自动获客助手] 已加载` 日志，带日志发 Issue。

**Q：提示「未找到评论按钮 / 评论区加载超时」？**
抖音改版导致页面结构变化。脚本对每个元素都有多个备用选择器和重试，偶发失败会自动跳到下一个视频；如果大面积失败，请提 Issue 附上日期，等更新。

**Q：AI 评论报错「API密钥未配置 / 请求失败 401」？**
Key 没保存成功或填错。检查：模型与 Key 是否配套（DeepSeek 的 Key 不能选在 Kimi 上）；余额是否用完；Ollama 是否已本地启动。

**Q：任务跑到一半不动了？**
等 5 分钟看门狗会自动恢复；或者直接「停止任务」重新开始（会从未处理的进度附近继续）。

**Q：怎么让评论看起来不像机器人？**
文案库多写几条口语化短句、开启 AI 并写好提示词、加大评论间隔、开启「回复前点赞」、优先用回复模式而不是直接评论。

**Q：一个账号能开几个任务？**
同时只能跑一个任务。开始按钮在任务运行中会拦截。

**Q：支持手机吗？**
不支持。本脚本运行于电脑版浏览器 + 抖音网页版。
